## Conventions

- **IDs** are auto-generated Firestore IDs unless noted.
- **Timestamps** are Firestore `Timestamp` server-side; the API serializes them to ISO strings.
- **Money** is always stored as integer cents in a separate `currency` field — never floats.
- **Soft-delete** is not used; deletes are hard.
- **Owner reference**: every collection that belongs to a user denormalizes `user_id` on the doc itself, so security rules don't need extra lookups.
- **Optimistic concurrency**: any client edit of `campaigns.strategy_json` sends `if_updated_at` matching the last-seen `updated_at`. The PATCH route compares before writing and returns 409 on mismatch.

## Collections

### `users/{uid}`

Created on first login. `uid` matches Firebase Auth.

| Field | Type | Notes |
|---|---|---|
| `email` | string | From Auth |
| `name` | string | Display name |
| `avatar_url` | string \| null | Optional |
| `plan_id` | string | `free` \| `pro` \| `team` |
| `subscription_id` | string \| null | Reference into `subscriptions` |
| `default_payment_method_id` | string \| null | Reference into `payment_methods` |
| `stripe_customer_id` | string \| null | Set once Stripe is wired up |
| `created_at` | timestamp | |
| `updated_at` | timestamp | |

```json
{
  "email": "senesh@example.com",
  "name": "Senesh Fernando",
  "avatar_url": null,
  "plan_id": "free",
  "subscription_id": null,
  "default_payment_method_id": "pm_1",
  "stripe_customer_id": null,
  "created_at": "2026-05-16T10:00:00Z",
  "updated_at": "2026-05-16T10:00:00Z"
}
```

### `campaigns/{campaignId}`

| Field | Type | Notes |
|---|---|---|
| `user_id` | string | Firebase Auth UID |
| `title` | string | |
| `goal_prompt` | string | The raw user prompt |
| `mode` | string | `all` \| `strategy` \| `flyer` \| `voice` — picked in the generation studio. Defaults to `all`. |
| `status` | string | `draft` \| `strategy_ready` \| `assets_ready` \| `published` |
| `strategy_json` | map \| null | Generated by Gemini — see [`CampaignStrategy`](#campaignstrategy-shape) |
| `event_id` | string \| null | Reference into `events` |
| `event_date` | timestamp \| null | Optional — only set in `all` mode |
| `audience` | string \| null | Optional — only set in `all` mode |
| `flyer_input` | map \| null | Only for `mode = "flyer"` — `{ visual_prompt, headline, subtext }` |
| `voice_input` | map \| null | Only for `mode = "voice"` — `{ script, voice_id }` |
| `created_at` | timestamp | |
| `updated_at` | timestamp | Stamped on every mutation. Sent back as `if_updated_at` on strategy PATCHes for optimistic concurrency — a mismatch returns 409 and the client reloads. |

#### `CampaignStrategy` shape

```ts
{
  summary: string,
  timeline: [
    {
      id: string,
      type: "tweet" | "linkedin" | "reel" | "email",
      scheduled_at: timestamp,
      copy: string,
      asset_refs?: { flyer_id?: string, audio_id?: string }
    }
  ],
  event_draft: {
    headline: string,
    subhead: string,
    body_md: string,
    form_fields: [
      { id: string, type: "text" | "email" | "select", label: string, required: boolean, options?: string[] }
    ]
  }
}
```

#### Sample document

```json
{
  "user_id": "u_abc123",
  "title": "Global React Summit 2026",
  "goal_prompt": "Host a worldwide virtual conference for React devs.",
  "mode": "all",
  "status": "published",
  "strategy_json": { "summary": "...", "timeline": [], "event_draft": {} },
  "event_id": "evt_xyz789",
  "event_date": "2026-06-15T15:00:00Z",
  "audience": "frontend engineers",
  "flyer_input": null,
  "voice_input": null,
  "created_at": "2026-05-14T09:00:00Z",
  "updated_at": "2026-05-16T11:00:00Z"
}
```

### `events/{eventId}`

| Field | Type | Notes |
|---|---|---|
| `campaign_id` | string | Parent campaign |
| `slug` | string | Unique. Used in `/e/{slug}`. Lowercased, kebab-case. |
| `published` | boolean | Public visibility flag |
| `landing` | map | `{ headline, subhead, body_md }` |
| `event_date` | timestamp \| null | Drives the public countdown timer. `null` hides it. |
| `location` | string \| null | Free-text location (e.g. `Virtual · Zoom + livestream`, `San Francisco, CA`) |
| `form_fields` | array | Registration form definition (see below) |
| `media` | map | `{ hero_url?, gallery_urls? }` — hero wallpaper + extra photos |
| `sponsors` | array | List of sponsors (see below) |
| `sponsors_display` | string | `grid` \| `carousel` — how sponsors render on the landing page |
| `attendee_count` | number | Server-incremented on registration — denormalized counter |
| `price` | map \| null | `null` = free event. See below. |
| `created_at` | timestamp | |
| `updated_at` | timestamp | |

#### `price` shape (paid events)

| Field | Type | Notes |
|---|---|---|
| `amount_cents` | number | Integer cents |
| `currency` | string | `USD` \| `EUR` \| `GBP` \| `INR` \| `LKR` |

#### `media` shape

| Field | Type | Notes |
|---|---|---|
| `hero_url` | string \| omitted | Full-width banner image at the top of the page |
| `gallery_urls` | string[] \| omitted | Ordered list — order in the array is the display order |

> Images go through `/api/upload`, which writes to Cloud Storage and returns a public URL. See [Storage paths](#storage-paths).

#### `sponsors[]` element

| Field | Type | Notes |
|---|---|---|
| `id` | string | Stable client-generated ID — used as the drag-and-drop key |
| `name` | string | Display name (fallback when no logo) |
| `logo_url` | string \| omitted | Public Storage URL |
| `website` | string \| omitted | Optional clickthrough |

#### `form_fields[]` element

| Field | Type | Notes |
|---|---|---|
| `id` | string | Stable client-generated ID — also used as the metadata key on attendees |
| `type` | string | `text` \| `textarea` \| `email` \| `phone` \| `url` \| `number` \| `date` \| `select` \| `checkbox` |
| `label` | string | Shown above the input |
| `required` | boolean | |
| `placeholder` | string \| omitted | Shown inside empty inputs (not used for `checkbox`) |
| `description` | string \| omitted | Help text below the field. For `checkbox` this is the label text. |
| `options` | string[] \| omitted | Required for `select`, ignored otherwise |

#### Sample document

```json
{
  "campaign_id": "camp_demo_react",
  "slug": "react-summit-2026",
  "published": true,
  "landing": {
    "headline": "Virtual React Workshop",
    "subhead": "Hands-on session — Friday, 3pm ET",
    "body_md": "Join us for a practical React workshop..."
  },
  "event_date": "2026-06-15T15:00:00Z",
  "location": "Virtual · Zoom + livestream",
  "form_fields": [
    { "id": "f3", "type": "text", "label": "Company", "required": false },
    {
      "id": "f4",
      "type": "select",
      "label": "T-Shirt Size",
      "required": true,
      "options": ["S", "M", "L", "XL"]
    },
    {
      "id": "f5",
      "type": "checkbox",
      "label": "Newsletter",
      "required": false,
      "description": "Subscribe to monthly product updates"
    }
  ],
  "media": {
    "hero_url": "https://storage.googleapis.com/.../hero.jpg",
    "gallery_urls": [
      "https://storage.googleapis.com/.../g1.jpg",
      "https://storage.googleapis.com/.../g2.jpg"
    ]
  },
  "sponsors": [
    {
      "id": "sp_1",
      "name": "Vercel",
      "logo_url": "https://storage.googleapis.com/.../vercel.svg",
      "website": "https://vercel.com"
    }
  ],
  "sponsors_display": "grid",
  "attendee_count": 42,
```

### `attendees/{attendeeId}`

| Field | Type | Notes |
|---|---|---|
| `event_id` | string | Parent event |
| `name` | string | |
| `email` | string | Lowercased on write — used as the dedupe key per event |
| `ticket_code` | string | Unique, human-readable (e.g. `TKT-A4F2-X8L9`). Used to look up the public ticket page at `/t/{code}`. |
| `metadata` | map | Custom form-field answers. Keys can be the field `id` or the field `label` — both are accepted. |
| `paid` | boolean | `true` if registered via paid checkout |
| `payment_id` | string \| null | Reference into `payments` for paid registrations |
| `amount_cents` | number \| null | Snapshot of price paid (in case event price changes later) |
| `currency` | string \| null | Snapshot of currency |
| `created_at` | timestamp | |

```json
{
  "event_id": "evt_xyz789",
  "name": "Maya Chen",
  "email": "maya@example.com",
  "ticket_code": "TKT-A4F2-X8L9",
  "metadata": {
    "Company": "Founder.cafe",
    "T-Shirt Size": "M",
    "Newsletter": "true"
  },
  "paid": true,
  "payment_id": "pay_abc123",
  "amount_cents": 2500,
  "currency": "USD",
  "created_at": "2026-05-16T16:42:00Z"
}
```

> **Counter**: bump `events.attendee_count` in the same transaction.
>
> **Ticket codes** must be globally unique within `attendees`. Generate with 8 base-32 chars (32^8 ≈ 1 trillion combinations) and retry on collision. Alphabet excludes ambiguous chars (`0`, `1`, `I`, `O`).
>
> **Re-registration** with the same email + event is idempotent — return the existing attendee + ticket code instead of creating a new row.

### `announcements/{announcementId}`

Broadcast emails sent from the campaign dashboard to an event's attendees. The doc is the audit trail; the actual delivery happens through your email provider (Resend, Postmark, SES, etc.).

| Field | Type | Notes |
|---|---|---|
| `event_id` | string | Parent event |
| `subject` | string | 2–140 chars |
| `body` | string | Plain text. Length validated `>= 4` chars in the API. |
| `channel` | string | `email` \| `in_app` — defaults to `email` |
| `recipient_count` | number | Snapshot of `events.attendee_count` at send time |
| `sent_at` | timestamp | When the send was kicked off (not when each email landed) |
| `scheduled_for` | timestamp \| null | Reserved for future use — send-later support |
| `created_by` | string | UID of the user who composed it |

```json
{
  "event_id": "evt_xyz789",
  "subject": "Speaker lineup just dropped",
  "body": "Hey everyone — we're stoked to share the full lineup...",
  "channel": "email",
  "recipient_count": 142,
  "sent_at": "2026-06-10T14:00:00Z",
  "scheduled_for": null,
  "created_by": "u_abc123"
}
```
